# PixelFlow 开发文档入口

这套文档根据项目内 `任务描述/1.png` 至 `15.png` 编制，用于指导后续 Agent 开发。本轮已按这套基线完成实现，实现范围、测试结果与**未验证项**见 [验收记录](验收记录.md)。

| 文件 | 用途 |
|---|---|
| [架构与开发规格](架构与开发规格.md) | 需求追踪、范围、技术选型、模块、身份、文件、状态机、接口语义、前端生命周期、交付边界 |
| [OpenAPI 契约](openapi.json) | 12 个 API 操作及请求、响应、鉴权、状态码的机器可读定义 |
| [数据库结构草案](schema.sql) | 9 张 MySQL 表、主外键、索引及约束；已转为 Flyway 迁移 `V1__init_schema.sql` |
| [开发计划与验收](开发计划与验收.md) | 分阶段计划、Agent 工作包、开发流程、核心测试、验收清单和派工模板 |
| [验收记录](验收记录.md) | A01—A16 逐条的真实执行结果、测试计数、修复缺陷与未验证清单 |

建议先完整阅读架构规格，再按工作包实施。原始截图中的要求属于必须满足的基线；匿名身份、串行队列、轮询、启动中断收尾属于本设计选择。依赖补丁版本、素材文件和种子记录由工程阶段补齐并验证。

任何 Agent 不得递归删除用户文件。验收清单默认未通过，实际实现与测试完成后才能记录为通过。
